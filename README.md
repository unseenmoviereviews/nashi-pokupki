# Наши покупочки

Каталог для двоих: то, что мы купили и оцениваем. Фото, цена, магазин, дата покупки,
оценки 1–5 по критериям от каждого, «купили бы снова?» и комментарии.

- **Сайт** — `index.html`, лежит на GitHub Pages.
- **Данные** — Google Таблица, фото — папка на Google Диске. Посредник между ними — `Code.gs` (Google Apps Script).
- **Вход** — личный ключ у каждого. Ключи хранятся только в Google (свойства скрипта), в этом репозитории их нет.
  В коде сайта нет ни данных, ни ключей.

Демо без сервера: откройте сайт с `?demo` в конце адреса.

## Настройка серверной части (≈10 минут, один раз)

### 1. Таблица и скрипт
1. Откройте https://sheets.new и назовите таблицу «Наши покупочки».
2. **Расширения → Apps Script**.
3. Удалите всё в `Code.gs` и вставьте содержимое [Code.gs](Code.gs) из этого репозитория.
4. В начале файла поменяйте имена в `MEMBERS`, если нужно: `const MEMBERS = ['Я', 'Сонюшка'];`
5. Сохраните (Ctrl+S).

### 2. Запуск setup
1. Вверху выберите функцию **setup** и нажмите **Выполнить**.
2. Google спросит разрешение: **Проверить разрешения** → выберите свой аккаунт →
   «Приложение не проверено» → **Дополнительные настройки → Перейти на страницу проекта (небезопасно) → Разрешить**.
   Это ваш собственный скрипт.
3. Внизу откроется **Журнал выполнения** с ключами:
   ```
   Я: 3f9c…
   Сонюшка: a71d…
   ```
   Сохраните их. Каждый ключ отдайте его владельцу, никуда не публикуйте.
   Показать ключи снова — функция `showKeys`, заменить на новые — `resetKeys`.

### 3. Публикация API
1. **Начать развертывание → Новое развертывание** → шестерёнка → **Веб-приложение**.
2. **Запуск от имени:** «От моего имени». **У кого есть доступ:** «Все».
   «Все» — это доступ к адресу. Без правильного ключа сервер ничего не отдаёт и не принимает.
3. **Развернуть** → скопируйте адрес (заканчивается на `/exec`).

### 4. Вход на сайт
Откройте сайт, вставьте адрес `/exec` и свой ключ. Браузер их запомнит.
Чтобы адрес не вводить каждый раз, его можно вписать в `const API_URL = '';` в начале `index.html`.
Он не секретный: без ключа он бесполезен.

На телефоне: «Поделиться» → **На экран «Домой»**.

## Изменения
- **Критерии** правьте на листе «Критерии»: одна строка на категорию, критерии через запятую.
- **После правок `Code.gs`:** Начать развертывание → Управление развертываниями → ✏️ → Версия: «Новая версия» → Развернуть.
  Адрес `/exec` при этом не меняется.
